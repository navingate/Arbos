Build a modern, premium marketing website for Astroware Inc. — an AI Alignment and Security research lab that also does AI consulting and advisory. We use Constitutional AI approaches to build state-of-the-art guard models and safety products.

## Tech Stack
- Next.js (App Router) + Tailwind CSS + TypeScript
- Framer Motion for subtle animations (scroll reveals, hover states)
- Responsive across all breakpoints (mobile-first)

## Design Direction
Reference: https://www.goodfire.ai/
- Dark theme with high contrast (deep charcoal/black background, white text, one bold accent color like electric blue or amber)
- Clean, editorial typography with generous whitespace
- Large hero headlines, minimal but intentional use of decorative elements (subtle grid patterns, gradients, or mesh backgrounds)
- Premium, research-lab aesthetic — not SaaS, not startup-y
- Smooth scroll behavior, section transitions
